Justine portfolio - how to put it online

1. Unzip this folder.
2. On github.com click New repository. Name it: portfolio. Click Create.
3. Click "uploading an existing file". Drag in index.html, style.css and the images folder. Click Commit changes.
4. Go to Settings > Pages. Under Branch choose main and folder / (root). Click Save.
5. After 1-2 minutes your link is: https://justinekendri26-pixel.github.io/portfolio/
